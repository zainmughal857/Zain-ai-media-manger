# ZAIN AI Media Manager — Mobile Web App

## Fastest way to use it
Upload these files to any HTTPS static hosting service. Open the URL on your Android phone in Chrome and choose **Add to Home screen**.

## Important
This version is the professional UI/prototype. Social publishing, OAuth, AI API calls and analytics need the FastAPI backend and official platform APIs.

The app intentionally does not ask for social-media passwords or bypass platform security.
